# Math Notebook 📜

A interactive, paper-card styled web application designed for 5th and 6th-grade students to practice core mathematics (integers, fractions, factoring, and algebraic identities). 

I created this project for my sibling, who is a math teacher, to help her students master concepts with clear visual fraction renderings, step-by-step pedagogical explanations, and localized feedback in both Azerbaijani and English.

### 🛠️ Built With
- React + Vite
- Lucide React (Icons)
- Canvas Confetti
- Deployed on Vercel
